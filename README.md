# Hi, I'm Matt 👋

I'm a **full-stack developer** with a particular interest in **data science**. I'm currently studying **Computer Engineering** at **Universidad Politécnica Salesiana (UPS)** in Ecuador.

## Featured Projects

- [**RAG Semantic Search Platform**](https://github.com/MattxPz/rag-semantic-platform) — A self-hosted platform for asking questions about technical PDFs. It runs locally with Ollama and highlights the source passages behind each answer directly in the PDF viewer.
- [**Chronolab**](https://github.com/MattxPz/chronolab-project) — A platform for time-series forecasting and anomaly detection that uses rolling-origin backtesting to evaluate models.
- [**Distributed Retail Intelligence**](https://github.com/MattxPz/distributed-retail-intelligence) — A distributed inventory simulator for a three-branch retail store. Each branch manages its own stock, and a central service maintains a consolidated inventory view. The current MVP includes branch and central APIs, persistent storage, and a dashboard. *In development.*
